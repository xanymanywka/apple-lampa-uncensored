# Apple Lampa Uncensored

Lampa Uncensored для macOS — нативное приложение (Apple Silicon и Intel, macOS 11 и новее).

💬 Сообщество: [@lampa_plugins_uncensored](https://t.me/lampa_plugins_uncensored)

## Установка

1. Скачайте `Lampa-Uncensored-….dmg` со страницы [Releases](../../releases/latest).
2. Откройте образ и перетащите значок в «Программы».
3. Первый запуск: правый клик по приложению → «Открыть» → «Открыть».
   Приложение не подписано платным сертификатом Apple, поэтому macOS спрашивает один раз.

Если macOS пишет «приложение повреждено», выполните в Терминале одну команду:

```bash
xattr -dr com.apple.quarantine "/Applications/Lampa Uncensored.app"
```

## Обновление

Само. Приложение проверяет новую версию в фоне, скачивает её и предлагает перезапуститься.
Ничего переустанавливать и разблокировать повторно не нужно. Вручную: меню
«Lampa Uncensored → Проверить обновления…».

## Плеер

Встроенный плеер не играет звук AC3/DTS (частая дорожка в раздачах) — это ограничение Chromium.
Выберите внешний: **Настройки → Плеер → «Плеер на этом Маке»** (или ⇧⌘P). Приложение само находит
установленные программы, умеющие открывать видео (VLC, IINA, mpv, Infuse, QuickTime и другие).
