# Выкладка обновлений

Приложение само проверяет `latest.json` у последнего релиза на GitHub.

## Новая версия приложения (≈200 МБ)

```bash
# 1. поднять "version" в package.json по смыслу (номер сборки поднимется сам)
npm run dist                                   # DMG + ZIP в dist/
npm run publish:release -- "что нового" "ещё пункт"
```

Скрипт создаёт релиз `vВЕРСИЯ-bСБОРКА`, кладёт DMG (для новых людей), ZIP и `latest.json`
(для установленных приложений). У людей появится окно «Обновление готово → Перезапустить».
Если нажать «Позже» — обновится при следующем выходе.

## Быстрое исправление без пересборки (килобайты)

Правите `patch/patch.js` (исполняется в странице Lampa, как плагин) и:

```bash
npm run publish:patch -- "что исправлено"
```

Подхватится при следующем запуске приложения. Патч действует только на сборки не старше релиза,
под который выложен. Чтобы снять патч — очистите файл и выложите новый релиз.

## Почему не electron-updater

Приложение подписано ad-hoc (без платного Apple Developer ID). Squirrel.Mac, на котором стоит
electron-updater, сверяет подпись новой версии со старой и отвергает ad-hoc. Поэтому обновление
свое: `lib/updater.js` качает ZIP, проверяет SHA-512 и подпись, отдельным скриптом подменяет
бандл после выхода и открывает новую версию. Скачанное приложением не получает карантин —
поэтому «приложение повреждено» после обновления не возникает.

Проверка локально: `LAMPA_UPDATE_FEED=http://127.0.0.1:8765/latest.json` + любой статический сервер.
